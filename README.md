# Spotifeishin 🎵

A clean, modern **Spotify Encore Hi-Fi** custom CSS theme for [Feishin](https://github.com/jeffvli/feishin).

Spotifeishin merges the elegant liquid-glass architecture and floating playerbar of **Fluentshin** with Spotify Encore's dark UI palette, dynamic cover-responsive lighting, interactive 3D depth, auto-hiding navigation, and next-generation lyrics.

---

## ✨ Features

- **Spotify Encore Aesthetics:** Pure deep carbon backgrounds (`#0E0E10` / `#070708`) with Spotify emerald accents (`#1DB954` / `#1ED760`).
- **Seamless Floating Liquid-Glass Playerbar:** Floating bottom bar with a high-contrast pure white Play/Pause action button (turns Spotify green on hover) and fluid background flow with zero black clipping borders.
- **Adaptive Dynamic Lyrics:** The active singing lyric capsule dynamically absorbs and amplifies the exact ambient colors of each album cover, paired with an aligned accent indicator pill and micro-blur depth on inactive verses.
- **Hover Top Bar & In-View Controls:** The native top window title bar stays completely hidden by default and reveals smoothly when hovering near the top edge. Media controls and lyric overlays feature balanced spacing with no cramped icon clutter.
- **Harmonized Album & Metadata Views:** Header titles blend into the album art using optical color-dodge, while right-side metadata cards and pills mirror the release's color palette without harsh cutoff lines.
- **Interactive 3D Cover Depth:** Hovering over album covers triggers a smooth internal perspective tilt with specular edge lighting.
- **Refined Media Actions:** Prominent Spotify green album play button with glassy secondary pills (*Next* and *Last*).
- **Polished Home Experience:** Ambient hero carousel with clean section headings and stabilized media grids.

## 🚀 Installation & Recommended Setup

### 1. Basic Setup
1. Open **Feishin**.
2. Go to **Settings → Appearance**:
   - Set **Theme** to `Default Dark`.
   - Set **Accent Color** to `#1DB954`.
3. Scroll down to **Custom CSS**, toggle **Enable custom CSS** on.
4. Copy the entire code from **`2.1.0.css`** (or `1.0.css` for the classic static style) and paste it into the CSS box.
5. Reload Feishin (`Ctrl + R` / `Cmd + R`).

### 2. Full-Screen / Lyrics Recommended Setup
To get the full immersive glass effect shown in the screenshots:
1. Open the **Full Screen Player** (Lyrics / Now Playing screen).
2. Click the floating settings gear icon inside the player.
3. Configure the following toggles:
   - **Dynamic Background (Fondo dinámico):** `ON`
   - **Enable Background Image (Habilitar imagen de fondo):** `ON`
   - **Background Blur Size (Tamaño de desenfoque):** High / Maximum
   - **Player Elements Alignment (Alineación de elementos):** `Center`
